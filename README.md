# Shubham Sinha — Placement Portfolio

A responsive, dark-themed developer portfolio built with React, Vite, Tailwind CSS v4 and Lucide icons.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. Extract this project and open the folder in VS Code.
3. Open the integrated terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```
